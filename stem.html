Inside a class

Learn it. Build it. Explain it.

Every Bayan STEM class ends with something you made and can explain.

  1. Learn it

    One idea, with a real-life example you already know.

  2. Build it

    An experiment, a model or a set of problems you solve live.

  3. Explain it

    Tell the class why it works. If you can explain it, you know it.

Questions

About Bayan STEM

Do we need lab equipment?

No. Experiments use everyday things: bottles, balloons, salt, torches. We send the list before each class.

Is this exam tuition?

No. Bayan STEM builds understanding that helps at school. For board exam preparation, see Bayan Academics.

My child finds maths hard. Will this help?

That’s who it’s for. Small batches mean the teacher can slow down and explain again.

Can my child join both STEM and Academics?

Yes. Many students use STEM for understanding and Academics for exam practice.
